Дескрипторы физического форматировнаия

В HTML все делается через дескрипторы

<p> (Paragraph) ― этот дескриптор описывает абзац;
<b> (Bold) ― этот дескриптор делает шрифт жирным;
<i> (Italic) ― этот дескриптор делает шрифт курсивным;
<u> (Underline) ― этот дескриптор делает шрифт подчеркнутым;
<s> (Strikeout) ― этот дескриптор делает шрифт перечеркнутых;
<sub> (Subscript) ― нижний индекс;
<sup> (Superscript) ― верхний индекс ;
<tt> (TeleType text) ― этот дескриптор делает шрифт монохромным (DEPRECATED);
Деск логического форматирования

Деск логического форматирования нужны для анализа страницы поисковыми машинами. Многие из них замещают дес-ры физического форматирования

<em> (Emphasis) ― этот дескриптор делает шрифт курсивным;
<strong> (Bold) ― этот дескриптор делает шрифт жирным;
<del> (Delete) ― этот дескриптор делает шрифт перечеркнутый;
<code> (Code) ― этот дескриптор делает шрифт монохромный;
<mark> (Mark) ― этот дескриптор делает шрифт выделенный;
<cite> (Cite) ― этот дескриптор делает шрифт цитаты;
